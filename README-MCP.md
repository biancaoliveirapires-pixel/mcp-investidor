# Como o MCP funciona aqui

1. O investidor define as regras no arquivo regras-mcp.json
2. O dev pede para o Copilot: "Cria uma API de pagamentos"
3. O Copilot consulta o MCP antes de responder
4. O código já vem pronto seguindo as 3 regras: leve, LGPD, com log de vendas

Sem MCP, o dev teria que lembrar as regras toda vez.
Com MCP, a IA já segue automaticamente.
